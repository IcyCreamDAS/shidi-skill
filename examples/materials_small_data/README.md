# Materials small-data ML demo · 材料小样本方法学示例

> **只用合成数据**的小样本「配方 → 性能」建模演示，展示 shidi 在 AI4S / 材料信息学方向上**怎么做得诚实**。
> *A synthetic-only, small-data formulation → property demo showing how this workflow keeps AI4S claims honest.*

---

## 这是什么 · What this is

一个可复现的最小闭环：配方特征（填料含量、添加剂 A、添加剂 B、熔融温度、基体黏度档）→ 性能（拉伸强度、弯曲模量、熔融指数 MFR）。数据由 `make_synthetic_data.py` 以固定随机种子生成，**120 行 / 6 个项目**，每个项目带不同的批次/产线偏移，用来模拟真实的"项目内相关、项目间漂移"。

**配方满足质量分数闭合约束**：填料 + 添加剂 A + 添加剂 B + 基体 = 100 wt%（基体为余量），生成器与 `run_demo.py` 都会断言这一点；候选配方另加 `matrix ≥ 40 wt%` 约束，避免采样出物理上不可能的配方。

*One reproducible minimal loop: formulation features → properties. The 120-row / 6-project dataset is generated by `make_synthetic_data.py` with a fixed seed, with per-project offsets that mimic batch/lab drift. Mass fractions close to 100 wt% in every row; candidates keep matrix ≥ 40 wt%.*

## 为什么是合成数据 · Why synthetic

真实的企业配方与测试数据受 NDA 约束，不能进公开仓库——但**方法可以公开**。本目录只放方法与合成数据，任何真实配方、牌号或客户信息都不应出现在这里。脚本启动时会校验 `data_source` 列，发现非 `synthetic` 行直接拒绝运行。

*Real industrial formulations are under NDA. The method is publishable; the data is not. Every row carries `data_source = synthetic`.*

## 演示了什么 · What it demonstrates

1. **分组留出验证（LOGO）**：按项目整组留出，而不是随机切分。同一项目的兄弟样本只差一点填料含量；随机切分会把"记住项目"当成泛化能力，把分数虚高。
2. **GP 不确定性 + 覆盖率自查**：每个预测点带 `mean ± sd`；在留出项目上统计 ±1σ / ±2σ 的实际覆盖率，和 68% / 95% 的理论值对照。
3. **零样本 vs 1-2 个基准配方的校准对比**：把新项目的 1-2 个基准配方加进训练集再预测，覆盖率**基本不变**——说明"跑两个基准就校准好了"是想当然；批次偏移需要混合效应模型才能识别。这个负结果本身就是方法学示范。
4. **ARD 特征相关性**：报告每个特征的 GP 长度尺度（越小越关键；停在上界 100 表示数据无法识别该特征的影响）。
5. **约束下的候选推荐**：采集函数用联合期望 `ECI(x) = EI(x) · P(MFR ≥ 28 g/10min)`，而不是硬阈值截断；同时给出"仅可行域内"的排行榜，两表并列。
6. **多目标 Pareto 前沿**：拉伸强度 vs MFR 后验均值的非支配集（独立 GP 的简化，见"不主张"）。
7. **模拟主动学习闭环**：推荐 → 合成 oracle 出"实验值" → 回填重训，重复 3 轮。
8. **口径标签**：输出表格里 `claim_label` 区分三类证据，见下。

## 口径规则 · Claim-label discipline

| 标签 Label | 含义 Meaning |
|---|---|
| `measured` | 数据集里的真实观测值（本示例中全部为合成值） |
| `predicted` | 模型输出，必须带 mean 和 sd；未经实验验证 |
| `exploratory` | 筛选级建议，**不得当作结论引用** |

**硬规则：探索级筛选范围 ≠ 统计置信区间。**
候选表里的 `tensile_screening_low/high` 是 `mean ± 2·sd` 的模型带；它是否有 95% 覆盖率，取决于上面的覆盖率表——本示例里实际覆盖率低于 68%，说明 GP 在跨项目时**低估**不确定性。因此这个带只用于排序候选，不能写成"95% 置信区间"。

*The screening band is a model band, not a confidence interval. Check the coverage table before quoting it.*

## 不主张什么 · What this does NOT claim

- ❌ 不主张能预测任何真实材料的性能：数据是合成的，响应面也是人为构造的
- ❌ 不主张这些 GP 分数能迁移到任何真实配方数据集
- ❌ 不主张多输出可独立建模：三个性能强相关（拉伸↔弯曲 ≈ 0.9），多任务 GP / 联合多目标采集（qEHVI）超出本示例范围
- ❌ 不主张 1-2 个基准配方就能校准批次偏移（实测覆盖率没变；正确做法是混合效应 GP）
- ❌ 不主张模型候选优于资深工程师的 DOE 直觉——那需要真实的"实验 → 回填"闭环
- ❌ 不主张 `mean ± 2·sd` 是置信区间

## 运行 · Run

```bash
pip install -r requirements.txt
python run_demo.py                          # 完整演示（数秒）
python run_demo.py --quick                  # CI 模式：小候选池 + 1 轮主动学习
python run_demo.py --priors priors_template.csv   # 用文献先验边界约束搜索空间
python run_demo.py --regenerate             # 重新生成合成数据
```

`priors_template.csv` 是「文献 → 搜索空间」的接口示例：列 `feature,min,max,note`。它**只约束边界**，不会把文献数值注入模型（不做先验均值）；换成你自己的文献调研结果即可。

输出写到 `outputs/`（已 gitignore，每次运行重新生成）：

| 文件 | 内容 |
|---|---|
| `outputs/report.md` | 完整报告（验证 / 校准 / ARD / 相关矩阵 / 候选 / Pareto / 闭环 / 口径 / 不主张清单） |
| `outputs/logo_metrics.csv` | 每个性能项的 LOGO R²、RMSE、覆盖率 |
| `outputs/calibration.csv` | 0/1/2 个基准配方下的覆盖率对比 |
| `outputs/candidates.csv` | ECI 候选 top-8（含可行标记、探索区间） |
| `outputs/pareto.csv` | 拉伸-MFR 的 Pareto 前沿候选 |
| `outputs/active_learning.csv` | 模拟闭环每轮的预测 vs 观测 |

## 文件 · Files

| 文件 | 作用 |
|---|---|
| `make_synthetic_data.py` | 合成数据生成器（固定种子、质量分数闭合；含真实响应函数供模拟 oracle 使用） |

## 与 shidi 的关系 · How it relates to shidi

shidi 的主线交付是文献调研 / 实验方案 / 作图 / 精读；这个目录补的是**方法学证据层**：当你说"帮我把配方-性能数据建模"时，它应该按这里演示的口径来做——分组验证、带不确定性的预测、三类标签分开、探索范围不当置信区间。文献数据按 `skills/shidi/references/data-extraction-schema.md` 的列结构抽取（测试标准 / 条件 / n / 误差 / value_type），再喂给这个示例。真实项目里再用 RDKit / polyBERT 描述符替换"代号"，并补「代号 → 化学身份」映射。
