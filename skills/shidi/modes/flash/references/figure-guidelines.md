# 科研图规范 + 统计报告规范

从 nature-figure 的流程思想 + 统计报告红线内化，与 chart skill 的配色/模板规范协同（作图执行细节以 chart skill 为准，本文件管科研图的"语义结构"）。

## 科研图制作流程（四步）

1. **数据语义确认**：先明确图的科学含义——要证明什么？X/Y 轴物理量是什么？分组逻辑？
2. **结构设计**：选图型（散点/柱状/热图/示意图），确定信息层级（主数据 > 辅助线 > 标注）
3. **渲染**：按 chart skill 规范写脚本渲染（配色/字体/dpi）
4. **自查**：读者能否不读正文就看懂这张图？（标题、轴标签带单位、图例自解释）

## 硬性规范

- 坐标轴必须有物理量 + 单位（如 `Wavenumber (cm⁻¹)`）
- 不隐藏异常点：异常数据标注但保留（数据真实性优先）
- 误差棒必须注明：SEM 还是 SD、n 是多少
- 色觉友好：避免红绿并置（复用 chart skill 的 Wong 配色）
- 灰度可辨：黑白打印场景下也能区分（线型/符号辅助）

## 示意图（论文摘要图/机理图）

- 化学结构用规范表示（Lewis 结构/骨架式，立体化学明确）
- 机理步骤编号 + 箭头方向一致
- 不做"艺术化"误导：示意图的几何比例不暗示真实构象（如超分子笼的大小标注需注明"示意，非真实比例"）

## 统计报告规范（红线）

1. 显著性检验必须声明：检验方法 + 样本量 + 显著性水平（p 值或置信区间）
2. 不画"无误差棒/无 n 数"的伪装柱状图
3. 统计不当 = 明确标注"统计方法待确认"，不硬算
4. 多重比较需注明校正方法（Bonferroni 等）
5. 拟合必须给出：模型形式 + 参数 + 拟合优度（R² 等）

## 交付物

- PNG（≥200 dpi）+ 可选的 PDF/SVG
- 脚本文件保留（用户可复现调参）
- 数据源路径记录在图注中
