# 分角度中间报告模板（angle-<角度代号>.md）

用途：**多角度任务（尤其后台并行派单）时，每个选定角度必须落盘一份中间文件**，汇总阶段只读这些文件——角度间互不干扰、主上下文不被撑爆、最终报告每段结论可溯源。

- 路径：`<任务目录>/assets/angle-<角度代号>.md`（如 angle-A1.md）
- 命名与角度代号一致（A1/A2/A3/B1/B3/C1…，用户选定为准）
- 单角度任务也可用：先落盘中间文件，再从它提炼最终报告

## 固定六段结构

```markdown
# 角度 <X>：<角度名称>

体系背景 / 本角度问题（各一句话）

## 一、检索记录
- T1/T2 query 列表（标出哪些命中核心文献、哪些 0 命中）
- T3 API 核验情况（Crossref/OpenAlex 逐条核验 DOI 的记录）
- 失败记录：WebSearch/WebFetch/fetch_pdfs 失败项如实登记（付费墙/反爬/网络不通）

## 二、论文卡片表（按七维总分排序，v2）
每篇：标题/期刊/年份 | 七维分（`score_papers.py` 复核后的总分）| 阅读深度 ✅/⚠/❌ | 核心发现 | 关键实验数据 | 对课题的意义
- 主题<10 一票否决，无淘汰时注明
- 补充/背景文献（专利、厂商资料、无 DOI 中文文献）单独列出，不入评分，标注"未验证"

## 三、文献总结（每段可追溯）
- 每条结论锚定具体文献编号；禁止空泛综述
- 对"本角度问题"给直接回答（允许标注"系外推/推理，非直接实验"）

## 四、可评价指标建议
- 从文献提炼"该测什么、怎么测、判据是什么"，逐条标注文献依据
- 区分优先级（最便宜最先）；厂商实践值标"未逐一核验原文"

## 五、参考文献（GB/T 7714 + DOI + 阅读深度）
每篇：作者. 题名[J]. 期刊, 年, 卷(期): 页码. DOI. ✅/⚠/❌（🔴=命中期刊清单）

## 六、缺口与不确定性（如实报告）
- 全文获取率；未读到全文的结论降级说明
- 文献空白（该领域无直接实验）——明说，不硬凑
```

## 硬规则

1. 每段结论都能指回第二节的卡片或第五节文献编号
2. 阅读深度逐篇标注，摘要级结论不得写成全文级语气
3. 失败记录不美化：检索 0 命中、全文 0 获取都要写出来
4. 文件写完即角度完成信号；子代理最终回复只给 5 行摘要，正文以文件为准

## 与最终报告的关系

最终报告（shidi_<主题>_<YYYYMMDD>.md）= 各角度文件的"综合判定"层：
分角度文件提供证据，最终报告负责交叉（角度间互相印证/矛盾处点名）、回答用户原问题、给裁决实验优先级与引子问题。最终报告引用分角度文献时保留原编号体系（如 [A2-1]、[C3-4]），正文不再重抄全部卡片——给出角度文件路径即可。
