# Shidi：Pro / Flash 模式路由

先判断用户需要哪种工作方式，再读取对应文件并完整执行，不混合两个版本的流程。

| 用户表达 | 模式与入口 |
|---|---|
| “师弟，帮我详细调研一下 XXX”或“师弟，请你用 pro 模式给我调研一下 XXX” | **Pro**：`modes/pro/SKILL.md` |
| “师弟，帮我快速调研一下 XXX”或“师弟，请你用 flash 模式给我调研一下 XXX” | **Flash**：`modes/flash/SKILL.md` |
| 未专门提到“详细”“快速”“pro”或“flash” | **Pro（默认）**：`modes/pro/SKILL.md` |

- Pro 适合需要完整检索框架、交互确认和结构化深度交付的任务。
- Flash 适合希望少确认、快速形成小范围方案并启动检索的任务。
- 同一请求同时出现两种表述时，以用户最后明确指定的模式为准。
- 模式选择只改变工作流程，不指定模型，也不保证某一模式在所有任务中质量更好。
- 论文精读、作图和其他任务也按所选模式文件中的分支执行。
