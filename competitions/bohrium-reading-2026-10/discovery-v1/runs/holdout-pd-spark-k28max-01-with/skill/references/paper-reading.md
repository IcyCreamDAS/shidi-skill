# 精读工作流（source-map 六步）

从 nature-reader 的设计（Router + source-map-first + 术语表）内化，裁剪到本环境。

**适用**：用户要求精读某篇论文 / 文献调研后选中某篇深入读。

## 核心原则

1. **source-map-first**：每个信息块必须能回溯到原文位置（页码/段落/图表编号），禁止凭记忆概括
2. **只读必要部分**：按需加载——PDF 分段读、HTML 只抓正文，不一次性吞全文
3. **术语表贯穿**：全程维护术语表（中英对照 + 定义），复用 `nature-shared` 的 Terminology Ledger 机制
4. **阅读深度与材料一致**：有全文且用户要求精读时，产出结构化精读产物；只提供摘要或缺页时，说明限制并请求所需材料，先交付可证实部分，禁止假装完成全文精读。窄问题按 `focused-reading.md` 交付，不强制展开整篇双语 reader。

## 六步工作流

### 第 1 步：建立来源映射（Source Map）
- 记录：标题 / 作者 / 期刊 / DOI / 年份 / 原文结构（章节标题、图表清单）
- 明确输入格式：PDF（可选中文本）/ 扫描件 / HTML / DOI / 粘贴文本

### 第 2 步：按结构逐段精读
- 顺序：摘要 → 图表 → 引言 → 结果 → 方法（方法最后，细节最多）
- 每段提取：核心主张 + 证据 + 位置锚点（段落/图号）
- 与用户课题（如超分子笼、耐磨涂层等研究方向）的关联点单独标记

### 第 3 步：图表提取
- 列出全部图表：图 N / 表 N + 一句话内容 + 位置
- 图表承载的结论（往往比正文信息密度高）

### 第 4 步：术语表登记
- 文中出现的关键术语：原文词 / 中文译名 / 定义 / 首次出现位置
- 输出为术语表表格（这是精读的核心产物之一）

### 第 5 步：产出结构化精读文档
- 默认格式：中英对照 reader（左原文右译文，图表原位）
- 或按用户要求：16 节论文卡片（见 paper-card.md）
- 公式/化学式：渲染为可读格式，不暴露原始 LaTeX（除非用户要求）

### 第 6 步：预响应核验清单
交付前逐项自查：
- [ ] 每个信息块都有来源锚点
- [ ] 术语表完整（≥5 个核心术语）
- [ ] 图表全部列出且位置正确
- [ ] 无凭记忆编造的内容
- [ ] 明确标注"无法确认"的部分（缺页、低质量扫描等）

## 扫描件处理

图片型 PDF：逐页读取（Read 工具按页读），低置信度区域标注"模糊，未确认"，不猜测内容。

## 版权注意

精读产物仅限个人学习使用，不完整复制原文长段落（引用注明出处）。
