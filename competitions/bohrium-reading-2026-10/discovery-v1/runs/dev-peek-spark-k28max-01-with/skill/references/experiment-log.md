# 实验记录标准化

从 nature-experiment-log 内化。实验方案分支 + 日常实验记录使用。

## 输入方式

- 文字描述（用户口述/粘贴）
- 图片（试剂标签、仪器读数、装置照片）
- 语音（用户描述实验过程）
- 数据文件（CSV/Excel 仪器导出）

## 输出方式

- Markdown 实验记录，带 YAML frontmatter（结构化字段，便于检索）
- 按实验 ID 归档到用户指定目录（默认 `~/lab-notes/`，可改）

```markdown
---
exp_id: EXP-2026-0803-01
batch_id: B-2026-0803-A
title: <实验名称>
objective: <目的>
status: 计划中 / 进行中 / 完成 / 失败
---
```

## 实验 ID 规则

- 格式：`EXP-YYYYMMDD-序号`（同日第几个实验）
- 每个实验一个 ID，不可复用；同一实验的补做 = 新 ID + 备注"补做 EXP-xxx"

## 样品批次 ID 规则

- 格式：`B-YYYYMMDD-字母`（同日第几批）
- 同一批次内样品编号：`B-20260803-A-01`、`B-20260803-A-02`…
- 批次变更（改配方/改条件）必须开新批次 ID，不混用

## 记录内容（每份必含）

1. 目的与假设（1-2 句）
2. 试剂清单：名称 / CAS / 供应商 / 纯度 / 用量
3. 仪器与参数：设备型号 / 关键参数
4. **测试标准与条件**：ASTM/ISO 编号 · 试样规格 · 拉伸速率/载荷/跨距 · 环境温湿度 · 样本数 n · 误差类型与数值（缺 → 标"未记录"，不猜）
5. 步骤（编号，含时间点）
6. 原始数据（或数据文件路径）
7. 观察现象（颜色/状态/异常）
8. 结果与判定（对照预期）
9. 问题与备选方案

> 需要跨文献/跨批次汇总数据时，按 `references/data-extraction-schema.md` 的列结构导出 CSV（同标准才可合并，实测/预测/探索三类标签分开）。

## 处理流程

1. 记录 → 2. 标准化（套模板+ID）→ 3. 归档 → 4. 更新实验索引（`lab-notes/index.md` 追加一行）
5. 用户可要求：数据图表化（调 chart skill）/ 与历史实验对比

## 注意事项

- 实验记录是**事实档案**：只记实际发生的，不替用户"补全"未做的步骤
- 数据缺失处标"未记录"，不猜测
- 试剂名称用规范名（中英对照 + CAS 号）
