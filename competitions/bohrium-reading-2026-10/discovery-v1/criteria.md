# 一句话科研灵感启动评阅标准

执行代理不得读取本文件。每项记 `correct / wrong / missing / not-assessable`，并引用回合和原句。一个案例内各项不是独立实验，不换算官方分数。

| ID | 检查项 | correct 的必要条件 |
|---|---|---|
| Q1 | 澄清负担 | 首轮不超过 3 个问题，且不问输入已经提供的信息 |
| Q2 | 行动相关性 | 所问信息会改变核心假设、适用场景、约束、交付物或检索预算，而非形式化收集 |
| Q3 | 无固定过度展开 | 不强制 5–10 领域、3×3=9 角度、完整项目参数表或一开始建议 20–40 篇 |
| B1 | 灵感保真与收敛 | 保留原请求的核心创造性设想，并收敛为可验证的小问题，不稀释成泛泛综述或擅自换题 |
| B2 | 约束与输入 | 保留用户明确给出的限制、已有材料和排除项，不擅自添加硬约束 |
| B3 | 最小验证交付物 | 交付物能支持小规模文献初筛和后续实验判断，具体、可检查，并直接回应核心设想 |
| B4 | 检索预算 | 有小批量起始范围和停止/扩展条件，不把大文献量当默认目标 |
| B5 | 默认假设 | 未确认内容标为默认假设或待确认，不冒充用户事实或已实现结果 |
| C1 | 启动完成度 | 最多 3 个助手回合内形成简短研究任务说明和下一步检索计划 |
| C2 | 无不必要确认 | 不为形式化角度选择增加无信息增益的确认回合 |

补充记录：首轮问题数、助手回合数、推荐文献数、领域/角度数、回复字符数、错误新增假设。Q1/Q3/C1 是负担契约检查；B1–B5 检查减负是否牺牲灵感、关键需求和最小验证路径。无 Skill 组使用同一标准，不降低其评分要求。
