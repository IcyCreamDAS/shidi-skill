# 材料论文阅读任务 B

请仅依据 input/ 中的论文，为复现实验准备一份中文方法核验单。重点是四种材料的配方基准、成型烧结过程、分阶段摩擦测试与磨损计算，以及作者的耐磨性能主张是否一致、哪些比较受到试验阶段差异限制。

交付 output/report.md 与 output/evidence.csv；CSV 至少含 claim_id、claim、value、unit、evidence_type、conditions、source_anchor、notes。数值和判断给出可定位锚点，核对正文与摘要、结论之间的冲突，未说明的字段明确标注。不得把体积百分比当质量百分比。不要从未提供的曲线读取点值，或把相关性说成因果性。

输入是全文 XML 与阅读副本，没有图像像素或补充材料。允许解析 XML 和计算，禁止联网或读取工作目录外的答案。核心输出总计不超过 24 KiB。直接完成可支持部分，列出待补材料。
