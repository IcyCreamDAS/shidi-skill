# 羧基化石墨烯/PEEK/PTFE：耐磨筛选阅读结论

**不支持将羧基化方案作为“耐磨优先”候选。** 在本文唯一的同名义填料量、同烧结实验对照中，GNS-COOH 组压缩强度更高，但磨耗量和所列磨损率均更高，拉伸强度及断裂伸长率更低。若应用主要受压、能接受耐磨和拉伸性能代价，可将其保留为条件候选；在本次耐磨筛选中，应优先保留未羧基化 GNS 对照复验。缺少重复数和误差，尚不能判定差异的统计显著性。[J01、X01–X06]

阅读范围：仅所给全文 XML 与确定性 Markdown 副本，论文 DOI 10.3390/polym16182572，PMC11435391。已直接核对 XML 表1–4及式1–3；未获得或查看图像像素、补充材料。下文方括号是 evidence.csv 的 claim_id；其 source_anchor 指向 XML 章节、表格行列或公式。本文所称“对照”均为 1%GNS/10%PEEK/PTFE；“羧基组”为 1%GNS-COOH/10%PEEK/PTFE。

## 2. 可借鉴的配方、制备和测试条件

### 配方与前处理

- PTFE 粉平均粒径40 μm，PEEK 粉24 μm，GNS 为多层、平均片径25 μm；PEEK 在150 °C干燥3 h，PTFE 过10目筛。保留原文“10目”，不自行改正。[P01]
- **比例基准：先以 PEEK:PTFE=1:9 质量比制备基体，再加入“1% GNS-COOH”。** §2模型也称 PTFE:PEEK=9:1、GNS质量分数1%。原文没有清楚解释该1%相对于预混基体还是最终复合物，也未明确官能团质量的计入方式；保留原始口径，不能直接改写为成品1/10/89 wt%。模型中的氧化度24.24%不是实验样品的实测羧基化程度。[P02、M01]
- GNS 经体积分数10%的 H₂O₂ 水溶液超声清洗，再于 KH550 硅烷偶联剂/丙酮溶液中超声分散，随后以“化学试剂法”制备 GNS-COOH；未给出完整羧基化反应条件。PEEK/PTFE 预混后用高速混合机充分混合，填料加入后同条件混合，再冷压、烧结；冷压压力/时长、混合时间/转速、超声参数、KH550浓度、后续试剂及洗涤干燥未报告，不能据此完整复现。[P03、L01]

## 3. 模拟与实验分开解读

### 模型与加载

Material Studio 8.0/Forcite，COMPASS力场，3×3×3 nm³周期性无定形模型，密度2.1 g/cm³；PTFE、PEEK分别描述为10个重复单元，实际链数未明确。模拟GNS-COOH氧化度24.24%。先最速下降/共轭梯度几何优化，再298 K下NVT/NPT动力学优化1000 ps；步长1 fs、压力101 kPa、截断12.5 Å，Andersen控温、Berendsen控压。随后自298 K升至340/350/360/370/380 °C，进行200 ps NVT优化，模拟烧结状态。[M01–M02]

力学采用恒应变法，原文写“constant strain rate 0.1%”，无时间基准，不能补为s⁻¹。式1给出 Eᵢ=σᵢ/εᵢ；Emax是三个方向的最大杨氏模量，非实验拉伸强度。B、G分别为体积/剪切模量；R、V为Reuss/Voigt，H为二者平均。原文将GH、BH都称体积模量是措辞错误，不能抹去剪切与体积的区别。[M03]

摩擦模型为Fe层/复合物/Fe层；相对滑速0.1 Å/ps（换算10 m/s），NVT 500 ps、初始298 K、步长1 fs。式2：μ=Ff/Fn，Ff=F₀+τAᶜ(L)；F₀为与载荷无关的Derjaguin偏移，τ为有效剪切强度，Aᶜ(L)为载荷L下接触面积。未明确摩擦法向载荷数值，101 kPa是模型压力设置，不能直接当成实验200 N。[M04–M05]

## 4. 机制、矛盾和适用边界

- §3.2.3认为360 °C模型RDF最大，报告RDF峰位1.37、2.49 Å，并据此推断氢键等相互作用。原子浓度沿z在14、41 Å有峰，文本给出14.1%、14.7%的峰值比较，但无可读曲线或原始数据，不能独立复算，比较口径亦不清楚。这些属于作者的机制解释，不是直接测得的宏观寿命证据。[Q01]
- §3.2.4报告340至380 °C的平均MSD分别为1.73、1.66、1.74、1.72、1.53 Å²，却由360 °C的“最大MSD”推论相对运动受限更强。较大位移量并不能直接证明运动更受限，需要原始时间曲线、分组和计算定义核验；不能把该解释当作已证实的因果关系。[Q02]
- 作者按SEM元素分布认为羧基组更分散、团聚减轻，但连接变弱；报告C下降20.8%、F上升51.2%、O下降80.5%。本输入只有文字及图注，缺少元素绝对值与图像像素，不能复算或自行宣称看见分散/剥落。图11文字称羧基组磨痕更粗糙并有片状脱落，只能注明为作者观察。[Q03–Q04]
- 模拟“360 °C比其他温度相互作用更强”与实验“羧基组比GNS连接更弱”用的是不同对照，并非必然互相否定；也不能把二者拼成羧基化提高耐磨的证据。引言将GNS-COOH称为“hydroxyl-functionalized”，与题名及后文carboxyl相冲突；实际化学身份和程度需确认。[J01、L03]
- 实验未提供无填料PEEK/PTFE或纯PTFE的同期对照，不能依据引言引述的前期工作，量化本次两方案相对这些基体的增益。证据限于该名义填料水平、烧结工艺、QT450配副、室温无润滑200 N/0.5 h条件；不覆盖高温、湿润/润滑、不同载荷配副或长期寿命。模拟时间、速度和界面模型与实验差异很大，未作预测精度校准。[L02]

## 5. 下一步最小核验

1. **先补可复现性与算术：**获取实际称料表及1%分母、完整官能化/混合/冷压/烧结气氛参数；确认5A几何、压缩强度判据、表4磨损率公式与原始称量，澄清正文百分比的分母。核验实际羧基身份/含量，不能直接使用模型24.24%。
2. **做最小独立复验：**两材料保持同基体比例、填料基准、制备批次安排及表面制样，在原摩擦条件复验磨耗质量和摩擦曲线，并复测压缩、拉伸、伸长；报告重复数、误差和检测分辨率。建议至少3个独立制样/测试重复作为先导核验（这是建议，不是论文已做的数量），再按离散性决定扩样。若要归因于羧基本身，另设匹配化学处理流程的对照。
3. **只有压缩优势满足设计需求时继续：**给出允许磨耗与最低拉伸/延展性门槛，再用实际服役载荷、温度、配副和时长验证。若要声称360 °C实验最优，至少补相邻350/370 °C实验筛查；若要声称优于基体，另加无填料基体对照。以上均为后续建议，非本文已验证结论。[R01]
