# 材料论文阅读任务 A

我在筛选耐磨聚合物材料。请仅依据 input/ 中提供的论文，判断这篇论文是否支持把羧基化石墨烯方案作为优先候选，并说明可借鉴的制备和测试条件、性能代价及适用边界。

请用中文交付 output/report.md 和 output/evidence.csv：

1. 阅读结论与依据；
2. 配方、制备、力学及摩擦磨损测试条件，明确比例基准；
3. 表格中模拟与实验的关键数值、对照关系及指标定义，核验关键性能变化；
4. 缺失信息、原文矛盾、不能据此下结论的部分与下一步最小核验需求。

CSV 每行对应一项证据，可自行增加列，至少包含 claim_id、claim、value、unit、evidence_type、conditions、source_anchor、notes。关键数字和判断必须能回查原文，不凭记忆补值。数值未提供时明确标注。输出要可直接供研发人员核对，核心输出总计不超过 24 KiB。

输入是开放全文 XML 与确定性阅读副本；未提供图像像素或补充材料。允许直接解析 XML 与进行数值计算。不得联网，不读取此工作目录外的答案或其他运行。除非信息缺失使继续完全不可能，直接完成可支持的部分并列出限制。
