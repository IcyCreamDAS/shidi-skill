# 材料论文证据核验：对照、换篇复用与中断记录

本轮开发试跑中，使用 Shidi 与不使用 Skill 的两个独立会话都找到了主要数据及表文差异。**目前不能声称 Shidi 提高了准确率或节省了时间。** 这一结果用于确定下一步开发方向，不是赛事成绩。

## 问题与方法

材料研发阅读不仅需要摘要，还需要把配方基准、制备条件、测试条件和指标定义对应到数值。为此增加了指定论文阅读入口，明确区分模拟/实测、制备/测试温度、原文未报告/输入未提供，以及作者报告/独立复算。

案例 A 使用 Dong 等的公开论文，DOI [10.3390/polym16182572](https://doi.org/10.3390/polym16182572)。原始 XML 与阅读副本见 [materials/A](materials/A/)，CC BY 4.0 署名和来源见 [SOURCES.md](materials/SOURCES.md)。它研究的是 PTFE/PEEK 复合材料，不是对任何企业配方的验证。

[任务](cases/A/task.md)、[验收标准](cases/A/criteria.md)、[参考检查项](evaluation/A-reference.csv)在执行前固定。两次新建会话不继承父线程历史，输入和预算相同；with 额外加载同一冻结 Skill。没有中途提示或人工补值。目录访问限制由指令约束，没有操作系统级隔离。参考答案未放进运行目录。

运行宿主为 ChatGPT Work Mode/Codex。均使用父线程继承的模型设置，未指定模型或推理等级覆盖；后台精确模型、采样设置、token和费用未向本任务暴露，记录为不可得。故这只是开发试跑，不能描述为已严格控制全部模型参数的正式实验。

## 实际结果

| 项目 | 使用 Shidi | 不使用 Skill |
|---|---:|---:|
| 预设适用检查项初核通过 | 27/27 | 27/27 |
| 终端调用次数 | 6 | 5 |
| 含编排包装层的保守调用计数 | 12 | 10 |
| 记录墙钟时间 | 610.134 秒 | 469.749 秒 |
| 核心输出大小 | 23,529 字节 | 23,165 字节 |
| CSV 数据行 | 83 | 41 |
| 生成失败后重试 | 1 | 0 |

评阅由主代理依据原始 XML 与预设参考逐项完成，未盲化、未经作者人工复核。不是独立人工金标准。A28针对未提供给执行代理的PEEK悬浮液/涂层应用背景，标为不可评估；原28项仍完整保留，处理理由见 [逐项记录](evaluation/A-pilot-assessment.csv)。即便将该项对双方同判遗漏，也不改变本轮增益为零的结论。

两组都正确指出：

- 抗压强度由104.2变为165.9 MPa，按原对照作分母是约59.21%的增加；正文写37.2%，对应的分母口径不同。
- 伸长率从216%到174%，是下降约19.44%，而非正文所述42.2%。
- 表列实验磨损率从0.067%到0.108%，相对增加约61.19%；正文38.4%不能由同一分母直接复现。
- 模拟原子脱离比例与实验表列磨损百分比不是可直接混算的指标；实验分母未明确。
- 对耐磨优先筛选，羧基组的抗压优势伴随拉伸与磨耗代价，不能写成全面改善。

这些是针对原文表3/4和相应段落的核验，不能据此直接判断整篇论文无效。双方输出还包含额外机制解释及建议，本次未对所有扩展主张作穷尽核验，不宣称“全部内容零错误”。

Shidi 把更多数值拆成独立行，并增加 DOI、value_type、standard、n 与误差字段；这是交付组织差异。行数更多不计作正确率提升。单组试跑的墙钟时间也不能用于估计总体速度差异。

## B：换篇复用已完成

在新会话中用同一冻结 Skill 阅读 Qi 等的另一篇论文，DOI [10.3390/polym15173626](https://doi.org/10.3390/polym15173626)。本轮使用包含正文外浮动表格的修正版阅读副本和完整原始 XML；修复及历史版本见 [ERRATA.md](evaluation/ERRATA.md)。Skill 内容与 A-with-02 一致，没有针对 B 运行途中修改或提示。

[16 项预设检查点初核通过](evaluation/B-pilot-assessment.csv)，包括体积分数配方、分阶段时长及总路程、磨损率定义、纯 PTFE 提前结束，以及不能把不同阶段结果当公平改进倍数。报告同时保留了摘要中的 1.76×10⁻⁴ 与正文/结论中的 1.76×10⁻⁶ mm³/(N·m)：两者相差100倍，不能静默替作者纠正。

实际用时407.707秒，6次终端调用（包含编排层时保守计12次），核心输出23,368字节、CSV 44行；没有执行失败或重试，两次展示截断后的定向读取有记录。评阅仍由主代理进行，未经盲评或人工复核；只检查了预设16项，没有穷尽审计所有扩展主张。B没有无Skill对照，**只能作为换篇可执行性的证据，不能据此计算Skill增益**。

## C：保存了输出，但运行记录不完整

仅给摘要的案例已经写出报告和CSV，之后会话返回模型用量限制错误，未留下 `run-notes.json` 或成功结束记录。因此状态为**中断且有部分输出**，不是完整完成的稳健性测试。保留原始文件，没有由主代理补写结束时间、用量、工具次数或原生轨迹。

[已保存文本的6项边界检查](evaluation/C-partial-assessment.csv)均观察到符合预期的行为：承认只有摘要，保留360°C及定性性能权衡，不补造配方百分比、测试标准或性能数值，用“输入中不可确认”而非“全文未报告”，并列出最少补充材料。这只能说明这些已保存文本的表现；不能证明整次执行完成、全程预算合规或获得官方C项分数。

核心输出16,148字节、CSV 18行；结束时间、总耗时、完整调用次数、token和费用均不可得。输入不足是预先构造的实验条件，与之后发生的宿主用量限制是两件不同的事。
